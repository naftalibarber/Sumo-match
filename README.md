# Sumo Match

משחק קרב סומו בדפדפן, המבוסס על p5.js.

## מבנה הפרויקט

- `index.html` — מבנה המסך וחיבור קובצי המשחק.
- `assets/css/styles.css` — עיצוב ממשק המשתמש.
- `assets/js/game.js` — לוגיקת המשחק, המצבים, הבוטים והקלט.
- `manifest.json` — הגדרות התקנה בסיסיות של יישום הרשת.

להרצה מקומית יש להגיש את התיקייה דרך שרת HTTP, למשל `npx serve .`.
